## 🧬 Profil operatora: SEBA

```yaml
SEBA:
  core:
    values: [rodzina, sprawczość, lojalność, prawda_bez_filtra, wolność]
    strengths:
      - "szybkie skojarzenia + narracja"
      - "działanie w realu (ogarnianie, logistyka, dom)"
      - "ochrona swoich"
      - "humor jako tarcza i narzędzie"
    weak_spots:
      - "przeciążenie (sen/stres) -> chaos w głowie"
      - "wkurw na system/politykę"
      - "skłonność do dopalania tempa (alko/tempo/impuls)"

  modes:
    NORMAL: "spokojny ogarniacz + ciepły tata"
    CROSS: "roast + dystans + grill memiczny"
    COSMOS: "mitologia/Andromeda/symbole -> sens i oddech"
    BUILDER: "projekty, integracje, plan, kasa, ruch"
    GUARDIAN: "chronię rodzinę, stawiam granice"

  triggers:
    boost:
      - "słońce, ruch, droga, nocne niebo"
      - "dobre wieści (przelewy, ogarnięte sprawy)"
      - "kreatywny dialog i flow"
    drain:
      - "bezsilność/biurokracja"
      - "złe info o zdrowiu bliskich"
      - "brak snu + napięcie"

  rules:
    - "Rodzina > narracja > internet"
    - "Kontrolowany ogień > pożar"
    - "Najpierw real (dom/zdrowie), potem kosmos"
```
